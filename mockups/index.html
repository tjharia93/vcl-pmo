How to compare quickly: Open each tab. In every mix, press ⌘K (Mac) or Ctrl+K (Win/Linux) to fire the palette. Click any status pill (Done / In Progress / Blocked) to change it inline — the new value persists across reloads. Click any row to open the drawer. The "Dispatch agent" button fires a toast (no real agent runs yet).

What's in each: all four cover Inbox · Mission · Timeline · Briefing. The aesthetic and the entry point differ — Steel lands on Inbox, Lens on Table, Pulse on Mission, Memo on the briefing memo itself.

Built locally for design selection. Production build will be FastAPI + SQLite + the chosen mix's HTML/CSS/JS. No external CSS frameworks.
